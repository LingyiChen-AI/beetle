# 飞书文档记录

先在当前目录的 `reports/` 下新建 `YYYY-MM-DD-<简短英文或拼音>.md`，严格按下面结构（字段顺序不能变）：

```
## <bug 标题，一句话>

**复现步骤**

1. ...

**修复建议**

1. ...（文件路径:行号）

**数据依据**：<关键查询结果的一句话摘要>

**提出人**：<姓名>

**提出时间**：<YYYY-MM-DD HH:MM>

**代码版本**：<分支> @ <提交号>
```

（「数据依据」「代码版本」两项和建 issue 共用；脚本只强制校验复现步骤、修复建议、提出人、提出时间四项的顺序。）

然后执行：

```
{{PYTHON}} {{SKILL_DIR}}/scripts/append_bug_doc.py reports/<文件名>.md
```

- 文档地址取运行时配置（环境变量 `BEETLE_RUNTIME`，客户端自动注入）里本群的 `doc_url`；也可以用 `--doc <飞书文档链接>` 指定。
- 看到「已写入并回读确认」才算成功。报「第一行必须是」「缺少字段」「字段顺序」就按提示修改 markdown 再执行。
- 本群没有配置 `doc_url` 时脚本会报错，此时不要写文档，在最终报告里写「未写入文档」。
- 文档里不出现口令、token、手机号、买家昵称或收货信息，需要时用店铺 ID / 记录 ID 代替。
